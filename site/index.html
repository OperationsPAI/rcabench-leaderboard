READING THE RESULTS

Understand the scores. Know the limits.

Full protocol ↗
01 / RANKING

Where does the first correct answer rank?

MRR averages the reciprocal rank of the first correct root-cause service; higher is better. A hit on any true root cause counts. Values are displayed as percentages.

MRR = mean(1 / first-hit rank)
02 / ACCURACY

Is the root cause among the top candidates?

Top@k is the fraction of cases with a true root cause among the first k predictions. Avg@k averages Top@1 through Top@k, not a separate set of samples.

Avg@k = mean(Top@1, …, Top@k)
03 / PROVENANCE

Traceable results. Visible failures.

The denominator is the number of requested cases. Missing or invalid results count as misses. Predictions are deduplicated by service by default; each row includes a pinned algorithm commit and a link to archived metrics.
